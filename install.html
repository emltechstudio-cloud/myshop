Install MyShop

Add to your home screen for instant access to your business hub — works offline, no app store needed.

📱 Install on iPhone / iPad

  1. Open Safari and visit myshop.afric.site
  2. Tap the Share button at the bottom
  3. Scroll down and tap "Add to Home Screen"
  4. Tap Add in the top right corner

🤖 Install on Android

  1. Open Chrome and visit myshop.afric.site
  2. Tap the menu (⋮) in the top right
  3. Tap "Add to Home screen" or "Install app"
  4. Tap Add or Install

💻 Install on Desktop

  1. Open Chrome, Edge, or Safari
  2. Look for the install icon in the address bar
  3. Click "Install MyShop"
